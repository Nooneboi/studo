Privacy

Local-first during Alpha.

Chee Skool Alpha does not require a learner account. Answers, notes, highlights, review history, theme preferences, and practice signals are stored in the browser on the learner's own device.

No Chee Skool learner database

The Alpha does not send practice history to a Chee Skool-operated learner database. Clearing browser site data can remove local progress, so the Progress page includes a download-and-restore backup tool.

Hosting requests

The website is delivered through GitHub Pages, so normal requests for pages and files are handled by GitHub's infrastructure. The current interface also loads web fonts from Google Fonts. Chee Skool code does not use advertising trackers or sell learner data.

Future changes

If accounts, cloud sync, analytics, payments, or other server features are added later, this policy must be updated before those features are enabled for learners.
