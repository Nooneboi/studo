# Alpha 32 — Extended Response Learning Hierarchy

**Release:** `0.7.0-alpha.32`

## Change

The Extended Response landing page now presents the learner path in instructional order:

1. Learning Units
2. Production Lab focused writing
3. Full Extended Response Practice

A compact jump bar remains above the learning index so returning learners can jump directly to any of the three sections. Desktop keeps the two practice banks side by side; narrow layouts stack Production Lab before Full ER.

## Scope

This is a hierarchy/discoverability change only. It does not modify ER prompts, production tasks, scoring, Mock content, Progress evidence, or curriculum counts.
