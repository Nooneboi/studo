# Phase 2.5 Learning System Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Align Progress, Train, module completion, Mock wording, subject navigation, and Home copy with the approved learner-system architecture.

**Architecture:** Add one small shared curriculum-routing helper for canonical skill/unit destinations and next-set sequencing. Keep the existing learning/content engines intact; change only the learner-flow glue and copy that currently contradicts the product rules.

**Tech Stack:** Static HTML/CSS/JavaScript, Node.js built-in test runner, generated JSON curriculum, GitHub Pages public build.

**Spec:** `docs/superpowers/specs/2026-08-25-phase2.5-learning-system-integration-design.md`

## Global Constraints

- Keep `content-src/` canonical and do not hand-edit generated modules as source.
- Keep Practice/Train/Skill Check/Mock delivery-role separation unchanged.
- Keep Guided modules `mock-excluded`.
- Add no new learner content, PDFs, Skill Checks, or Mock-only bank items.
- Do not enforce `release-gate.json` in GitHub Actions in this phase.
- Preserve learner-only public-build boundaries.

### Task 1: Canonical curriculum routing

**Files:**
- Create: `js/curriculum-routes.js`
- Modify: `progress.html`, `module.html`, `js/progress.js`, `js/module.js`, `scripts/build-public.mjs`
- Test: `scripts/phase25-learning-system-integration.test.mjs`

**Interfaces:**
- Produces: `window.CurriculumRoutes.build(curriculum)`, returning `{ hrefForSkill(skillId), nextSet(file) }`.
- `hrefForSkill(skillId)` returns a canonical `skill.html` URL or `practice.html` fallback.
- `nextSet(file)` returns `{ title, file, returnHref }` for the next set in the same curriculum item, or `null`.
