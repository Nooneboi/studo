# Chee Skool — RLA Learning Methods Matrix V1

Date: 2026-08-23
Status: Research/design baseline — not yet an implementation spec

## Core design rule

Every title should move the learner through five stages:

1. **See it** — concise explanation + worked example + purposeful visual.
2. **Manipulate it** — sort, match, rank, order, select, or complete something.
3. **Explain / produce it** — paraphrase, justify, rewrite, summarize, or build an answer.
4. **Test it** — GED-style interaction with scaffolding removed.
5. **Remember it** — spaced mixed review later, preferably with a changed context or format.

No interaction is added only because it is visually interesting. The method must make the underlying reasoning more visible or produce better practice.

## Method families Chee Skool should support

### Visual / organizational
- Graphic organizer (learner-completed, not decorative)
- Comparison matrix / Venn-style organizer
- Sequence / timeline organizer
- Cause-effect chain
- Argument map
- Evidence ladder / evidence-quality scale
- Source comparison grid
- ER planning organizer

### Active manipulation
- Matching
- Sorting / classification
- Drag-and-drop ordering
- Drag-and-drop categorization
- Ranking
- Select sentence / phrase / paragraph
- Inline dropdown / cloze
- Sentence reconstruction

### Generative practice
- One-sentence gist / summary
- Paraphrase
- Short constructed justification
- Self-explanation: “Why does this answer work?”
- Rewrite / revise
- Sentence combining
- Build-a-thesis / build-an-argument
- Evidence-to-reasoning explanation

### Error / contrast learning
- Error hunt
- Find the trap distractor
- Too broad / too narrow / unsupported classification
- Strong vs weak response comparison
- Before/after revision comparison
- Supported vs unsupported reasoning

### Retention / transfer
- Retrieval without answer choices
- Mixed-skill discrimination
- Spaced review
- Same skill in a new context
- Same content represented in a different format

## GED interaction fidelity

Current official public RLA format includes multiple choice, drag-and-drop, select-an-area, drop-down, and one Extended Response. Chee Skool should therefore build real support for:

1. **Multiple choice** — already strong.
2. **Inline dropdown** — present in part of Mock; should be expanded for editing.
3. **Drag and drop** — new engine: sort and order modes.
4. **Select area** — new engine: sentence, phrase, paragraph, table/graphic region where appropriate.
5. **Extended Response** — already present; teaching around it should become more interactive.

## Interaction engines to build first

### Priority 1 — Inline dropdown
Why first: it is a direct GED RLA editing format and we already have partial support.

Must support:
- multiple dropdowns embedded in a passage
- keyboard operation
- reset/review states
- answer explanations tied to each edited location
- Mock + Practice use

### Priority 2 — Select area
Why second: it is exceptionally useful for RLA because evidence is located inside text.

Must support:
- sentence selection
- phrase selection
- paragraph selection
- accessible keyboard alternative
- correct/incorrect feedback in Practice
- no feedback during Mock

### Priority 3 — Drag and drop
Why third: covers both exam familiarity and powerful learning tasks.

Two modes only at first:
- **Sort** — move cards into categories
- **Order** — put cards in sequence

Accessibility requirement: every drag action needs a non-drag alternative (e.g. select card → choose destination / move controls).

## Telegram-friendly learning formats

- One-image organizer + short explanation
- Fillable PDF version
- “Try this” post with a short passage and organizer
- Matching/sorting image challenge followed by answer post
- Weekly printable practice sheet
- “Find the trap” carousel/image set
- Before/after revision post
- Evidence ranking challenge
- Daily short read + one generative task

Telegram should expose the method and provide useful stand-alone practice; Chee Skool should hold the full guided path, interactive engine, explanations, saved progress, spaced review, and mastery evidence.

## Research basis used for V1

- GED Testing Service — public RLA exam format and Assessment Guide for Educators: multiple choice, drag/drop, select-area, dropdown, Extended Response; RLA dropdown layout is used for editing items.
- What Works Clearinghouse / IES — explicit comprehension strategy instruction; world/word knowledge; questioning; gist routines; comprehension monitoring; stretch text.
- What Works Clearinghouse / IES — spacing, interleaving worked examples with practice, combining graphics with verbal explanations, and quizzing/retrieval.
- What Works Clearinghouse / IES — secondary writing: Model–Practice–Reflect cycle and integrating reading/writing.
- 2024 Review of Educational Research network meta-analysis — more comprehension strategies are not automatically better; main idea, text structure and retell were particularly useful together when background knowledge was included.
- 2025 Educational Psychology Review meta-analysis — learner-generated and instructor-provided graphic organizers both showed benefits for learning from text, with caution about publication bias.
- AERA Open 2020 meta-analysis — well-designed graphics showed a moderate overall positive effect on reading comprehension.
- CommonLit research base — purposeful annotation, text structure, modeling and read-think-highlight rather than indiscriminate highlighting.
- Quill — sentence combining, grammar, proofreading, short writing activities and revision-oriented feedback as useful design references.

## Rules before implementation

1. Do not add an interaction because it is “fun.” It must improve reasoning, transfer, or exam familiarity.
2. Do not teach every skill with every method. A 2024 meta-analysis found that adding more strategy types is not automatically better.
3. Visual organizers must be purposeful and learner-completed where possible.
4. Scaffold heavily at the beginning, then fade help.
5. Every skill needs an independent GED-style check after the learning activity.
6. Every major skill should return later through spaced and mixed practice.
7. Background knowledge should be supported when unfamiliar topic knowledge could block comprehension.
8. Telegram assets should be original Chee Skool designs; external worksheet sites and Scribd are discovery/inspiration sources, not copy sources.
