# Chee Skool — Main Idea / Central Idea Model Title V1

**Purpose:** Create the reference learning architecture that future RLA titles can adapt rather than copy mechanically.

## 1. Current Chee Skool baseline

Chee Skool already has:
- Main Idea Study Guide (5 pages)
- Main Idea Workbook 1 (6 passages / 12 focused questions)
- Main Idea Workbook 2 (transfer practice across informational, science, workplace, and literary contexts)
- 12 canonical online R1.2 questions directly tagged to Main Idea / Central Idea
- additional Main Idea appearances inside Passage Practice and transfer sets
- explicit + implied central-idea families in the item-development standard
- distractor logic already covering supporting detail, too broad, too narrow, incomplete, and unsupported generalization

**Conclusion:** the foundation is good. The gap is not “we need another basic worksheet.” The gap is a structured path from understanding → guided manipulation → explanation → exam-style independence → later retrieval.

## 2. Research-backed instructional decisions

### Explicit instruction + guided practice + independence
IES adolescent-literacy guidance recommends direct and explicit comprehension-strategy instruction. It specifically includes summarizing, paraphrasing, finding the main idea, questioning, graphic organizers, teacher modelling, guided practice/feedback, scaffolding, and eventual independent practice.

**Chee Skool implication:** Main Idea should not start with an unassisted test. Learners should first see the reasoning, then perform parts of it, then solve independently.

### Topic → details → central idea
Khan Academy distinguishes the topic from the central idea and asks learners to identify what the author wants the reader to understand about the topic. It also emphasizes that a central idea should cover most important details and should not focus on one detail, introduce unsupported information, or contradict the text.

**Chee Skool implication:** Teach topic and central idea as separate decisions. Build distractor diagnosis directly into practice.

### Summarize before answer choices
Khan Academy recommends summarizing the text in the learner’s own words before matching that prediction to answer choices. EduWorksheets similarly recommends identifying the topic and creating a short one-sentence summary before selecting the main idea.

**Chee Skool implication:** learners should sometimes produce a short main-idea statement before seeing choices. This reduces answer-choice cue dependence.

### Active graphic-organizer use
IES supports graphic organizers as part of explicit comprehension instruction. Reading Rockets recommends a progression from completed organizers → partially completed organizers → blank organizers as learners become more independent.

**Chee Skool implication:** one organizer should exist in three scaffold levels rather than as a single static worksheet.

### During-reading checks and synthesis
CommonLit main-idea lessons use short during-reading checks on section main ideas/key details, followed by whole-text synthesis.

**Chee Skool implication:** for longer passages, use optional section-level “What matters here?” checks before asking for the whole-text central idea.

## 3. The Main Idea learning path

### Stage A — SEE IT
Goal: understand the construct without pressure.

1. **Quick Guide** — keep and refine current guide.
2. **Worked Example 1: explicit central idea**
   - passage
   - topic identified
   - key details marked
   - one-sentence central idea
   - distractors diagnosed
3. **Worked Example 2: implied central idea**
   - no single sentence states the answer
   - learner sees how multiple details are combined
4. **Main Idea Visual Organizer — Level 1 (completed)**
   - Topic
   - Key Detail 1
   - Key Detail 2
   - Key Detail 3
   - “What do these details show together?”
   - Main Idea
   - Scope Check: too narrow / too broad / unsupported / fits the whole text

### Stage B — MANIPULATE IT
Goal: make the learner actively classify relationships.

5. **Topic vs Main Idea matching** — 6–8 pairs
6. **Detail or Main Idea sorting** — 8–10 cards
7. **Distractor Trap Sort**
   - Too narrow
   - Too broad
   - Unsupported
   - Contradicts text
   - Best fit
8. **Main Idea Organizer — Level 2 (partially completed)**
   - passage supplied
   - some key details supplied
   - learner completes remaining details + main idea
9. **Select the Evidence**
   - click/select the 2–3 sentences that most strongly develop the central idea

### Stage C — EXPLAIN / PRODUCE IT
Goal: reduce dependence on recognition-only questions.

10. **One-Sentence Main Idea**
    - learner writes own answer before seeing choices
11. **Why This Fits**
    - learner chooses the two details that best justify their main-idea statement
12. **Why This Is Wrong**
    - learner receives a tempting distractor and labels the error
13. **Compare Two Answers**
    - choose stronger central-idea statement
    - explain why it has better scope/precision
14. **Main Idea Organizer — Level 3 (blank)**
    - learner decides which details matter

### Stage D — TEST IT
Goal: GED-style independent performance.

15. **Focused Set A — direct/explicit** — 8 questions
16. **Focused Set B — implied** — 8 questions
17. **Transfer Set** — 8 questions across science/workplace/civics/literary
18. **Long-Passage Application** — 2–3 passages, 400–900 words
19. **Mixed Trap Set** — main idea vs summary vs supporting detail vs author purpose
20. **Mastery Check** — 10–12 questions, no hints or organizer

### Stage E — REMEMBER IT
Goal: long-term retention and discrimination.

21. **Spaced Review** — 3–5 Main Idea items resurfaced later
22. **Mixed Core Meaning Review** — Main Idea mixed with Explicit Meaning, Supporting Details, Summary, Theme
23. **Train resurfacing** — missed/low-confidence Main Idea families return in new contexts

## 4. Interaction formats to support

### Already available
- Multiple choice
- confidence check
- highlighting / notes

### New reusable engines needed
1. **Select Area / Select Text**
   - sentence
   - phrase
   - paragraph
2. **Drag & Drop Sort**
   - category bins
3. **Drag & Drop Order**
   - sequence/order
4. **Matching**
   - card-to-card relationships
5. **Inline Dropdown**
   - especially for Language; not central to Main Idea but part of shared exam-fidelity work
6. **Short Constructed Response**
   - one-sentence answer stored locally; compare with model/rubric rather than pretend-scoring it

For Main Idea specifically, the highest-value new formats are **Select Text, Sorting, Matching, and Short Constructed Response**.

## 5. Main Idea method library

| Method | Learner action | Why we use it |
|---|---|---|
| Topic → Central Idea | Separate subject from author’s point | Prevents “topic = main idea” confusion |
| Key-detail selection | Identify details that matter most | Builds synthesis |
| One-sentence prediction | State answer before choices | Reduces cue dependence |
| Scope Check | Test too narrow / broad / unsupported / contradiction | Teaches distractor logic |
| Trap Sort | Classify wrong answers | Makes error patterns visible |
| Evidence selection | Select sentences supporting the central idea | Links answer to text evidence |
| Compare two answers | Judge precision and coverage | Builds discrimination |
| Worked example fading | Full → partial → no organizer | Gradually removes scaffolding |
| Section gist | Summarize chunks of long text | Supports long-passage comprehension |
| Mixed review | Distinguish Main Idea from neighboring skills | Tests transfer rather than repetition |

## 6. Target content depth for the finished title

Do **not** interpret these as quotas that justify filler. They are coverage targets.

- 2 worked examples
- 3 visual-organizer scaffold levels
- 4–6 short active-learning activities
- 24–30 focused Main Idea questions across direct + implied forms
- 8–12 transfer questions in unfamiliar contexts
- 8–10 discrimination questions involving neighboring Core Meaning skills
- 2–3 longer passage applications
- 10–12 independent mastery items
- 3–5 later spaced-review items per review cycle

**Expected meaningful exposures:** roughly 50–70, with different cognitive demands rather than 50 copies of “Which statement is the main idea?”

## 7. Difficulty progression

### Level 1 — Obvious
- short text
- explicit central idea
- clear details
- obviously wrong distractors

### Level 2 — Connected
- central idea implied by multiple details
- true-but-narrow distractors
- learner must synthesize sections

### Level 3 — Qualified
- benefits + limitations / claim + qualification
- certainty language matters
- distractors are partially true

### Level 4 — Transfer
- unfamiliar science/workplace/civic/literary context
- central idea may emerge from structure or character change

### Level 5 — Mixed / Exam
- no skill label in the question
- Main Idea mixed with summary, purpose, inference, theme, and evidence
- normal test tools only

## 8. Telegram version

Telegram should expose useful pieces without becoming the full course.

### Post 1 — Visual
**Main Idea Scope Check** image
- Topic
- 3 key details
- One-sentence main idea
- Too narrow / too broad / unsupported / best fit

### Post 2 — 3-minute challenge
Short passage + learner writes one sentence before opening the answer/reply.

### Post 3 — Trap Quiz
Telegram poll: “Which answer is too narrow?”

### Post 4 — Evidence challenge
Image or short passage: “Which two sentences matter most to the central idea?”

### Post 5 — Printable organizer
A clean single-page fillable/printable Main Idea organizer.

### CTA
“Want full guided → transfer → mastery practice? Continue Main Idea on Chee Skool.”

Telegram provides discovery/repetition. Chee Skool provides the complete learning loop and learner state.

## 9. Content trust rules

Every new Main Idea passage/question should record internally:
- skill + family
- difficulty
- context
- source/fact provenance
- original/adapted/public-domain status
- distractor logic
- answer rationale
- review date
- reviewer/QA status

For factual passages, prefer reliable primary/academic/public sources and write original Chee Skool passages rather than copying commercial prep material.
