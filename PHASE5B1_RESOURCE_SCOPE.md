# Phase 5B.1 — Resource Placement

Studo now supports two resource attachment levels.

## Topic-level resources
Use for material covering a whole domain/topic.

Example:
- RLA → Core Meaning → Core Meaning Quick Study Guide
- RLA → Core Meaning → Core Meaning Practice Pack

These render beside the topic title on the domain page and do not appear as files for every individual skill.

## Skill-level resources
Use for material written specifically for one sub-skill.

Example:
- RLA → Core Meaning → Main idea / central idea → Main Idea Worksheet
- RLA → Core Meaning → Summary → Summary Practice

These render only on that skill's page and mark only that skill as having study files.

## Resource Studio
Resource Studio now asks:
1. Attach to: Whole topic / Specific skill
2. Topic / domain
3. Specific skill (only when needed)

## Validation
The validator checks:
- valid topic IDs
- valid skill IDs
- topic/skill placement mismatches
- file paths, publishing status, and rights metadata
